Arduino MIDI Clock

Прошивка V3.3

Компактный MIDI Master Clock для синтезаторов, драм-машин, секвенсоров и другого MIDI-оборудования. Темп задаётся потенциометром или Tap Tempo, Start/Stop управляется одной кнопкой, а настройки сохраняются в EEPROM.

О проекте

M

MIDI Clock

Аппаратный MIDI Clock через D1/TX0 со стандартной скоростью MIDI 31 250 бод.

T

Tap Tempo

Минимум три коротких нажатия TAP позволяют быстро задать новый BPM.

B

BPM Display

4-разрядный TM1637 отображает BPM и служебные состояния устройства.

E

EEPROM

Настройки сохраняются между выключениями питания. Повторная запись выполняется только при изменении значения.

N

BPM Nudge

Потенциометр на A0 плавно изменяет BPM относительно откалиброванного центрального положения.

S

SYNC OUT

Дополнительный SYNC OUT можно включить отдельно через compile-time опцию.

Управление

Орган управления Действие Результат
TAP — D2 ≥ 3 коротких нажатий Расчёт и установка нового BPM.
TAP — D2 Удержание ≥ 5 секунд Переключение Clock Always / Clock Only When PLAY. Состояние сохраняется в EEPROM.
A1 Короткое нажатие Переключение PLAY / STOP и передача MIDI Start / Stop.
A1 Удержание ≥ 3 секунд Калибровка центра потенциометра. На дисплее — CAL.
TAP + A1 Удержание ≥ 4 секунд Переключение LOCK / UNLK потенциометра. Состояние сохраняется в EEPROM.
Потенциометр — A0 Поворот Изменение BPM, если влияние потенциометра не заблокировано.

Основные режимы

Clock Always — CALL

MIDI Clock передаётся постоянно независимо от состояния PLAY.

Clock Only When PLAY — CPLY

MIDI Clock передаётся только во время PLAY. Режим переключается удержанием TAP не менее 5 секунд.

LOCK

Влияние потенциометра на BPM отключено. Это защищает темп от случайного вращения ручки.

UNLK

Потенциометр снова может изменять BPM.

CAL

Калибровка текущего положения потенциометра как центральной точки BPM Nudge.

PLAY / STOP

Одна кнопка A1 управляет MIDI Start и MIDI Stop.

Подключение

MCU Arduino Nano / ATmega328P-совместимая плата
MIDI OUT D1 / TX0, 31 250 бод
TAP D2
Start / Stop A1
BPM Nudge A0, потенциометр
Tempo LED D5
Display TM1637, 4 разряда
SYNC OUT D8 при включённом ENABLE_SYNC
Важно: D1/TX0 используется непосредственно для MIDI OUT. Не открывайте Serial Monitor во время работы устройства, поскольку Serial и MIDI используют один аппаратный UART.

Опциональные функции V3.3

SYNC OUT

// #define ENABLE_SYNC 1

Добавляет SYNC OUT, меню SYNC, выбор делителя, инверсию полярности и сохранение настроек.

Restart from bar 1

// #define ENABLE_A1_DOUBLECLICK 1

Двойной клик A1 выполняет SPP = 0 и MIDI Start.

Фазовый индикатор

// #define ENABLE_BEAT_SEG 1

Средний сегмент G первой цифры слева мигает один раз за такт.

Фаза только в PLAY

// #define BEAT_SEG_ONLY_WHEN_PLAY 1

Фазовый индикатор работает только во время PLAY.

Полярность

Полярность SYNC можно изменить отдельным параметром. Настройка сохраняется в EEPROM.

Ширина импульса

Фиксированная ширина SYNC импульса: 15 мс.

EEPROM

Между выключениями питания могут сохраняться:

  • BPM;
  • центр потенциометра;
  • LOCK / UNLK;
  • Clock Only When PLAY;
  • параметры SYNC, если функция включена.

Запись в EEPROM выполняется только при изменении значения, что уменьшает количество циклов записи и продлевает ресурс памяти.

История проекта
